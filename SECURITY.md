# Security

If you find a security issue in the AirInduct Sim desktop app, the web app
(app.airinductsim.com) or the API (api.airinductsim.com), please report it privately to
**info@airinductsim.com** with "Security" in the subject. Do not open a public issue.

Please include:

* what you found and its impact,
* steps to reproduce (and the app version: AirInduct Sim → About),
* your platform (macOS / Windows / Linux and version).

We acknowledge reports within three business days and keep you updated until the issue is
fixed. We ask that you give us reasonable time to fix the issue before disclosing it.

Only the latest release of the desktop app receives security fixes; the app updates itself
when a new version is published.
